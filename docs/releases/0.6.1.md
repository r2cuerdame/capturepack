# CapturePack 0.6.1

CapturePack 0.6.1 is the first public build since 0.5.1: one-click full-page
Chrome capture, Shadow DOM picking, Git context in packs, solid Share Copy
masking, safer updates, and many History and save fixes.

## 바뀐 점

- 크롬 툴바 아이콘 한 번으로 페이지 전체를 캡처해 보통 정지 화면 편집기로 엽니다. 고해상도 화면에서도 됩니다 ([#157](https://github.com/r2cuerdame/capturepack/issues/157)).
- 크롬에서 열린 Shadow DOM 안의 요소도 고르고 문서 스냅샷에 담습니다. 한 페이지 앱의 주소 바뀜도 따라갑니다 ([#345](https://github.com/r2cuerdame/capturepack/issues/345)).
- 공유 사본(Share Copy)의 가림을 단색으로 칠해 원래 픽셀을 남기지 않을 수 있고, 다중 모니터에서 가림이 빠지던 문제를 고쳤습니다 ([#566](https://github.com/r2cuerdame/capturepack/issues/566)).
- 저장할 때 Git 저장소·브랜치·커밋·바뀐 파일 목록을 함께 남깁니다. 100ms 안에 못 읽으면 건너뛰고 저장은 그대로 합니다.
- 내려받은 업데이트는 앱을 끌 때나 강제 종료 뒤 다음 시작 때 설치하고, 캡처·저장 중에는 설치하지 않습니다 ([#149](https://github.com/r2cuerdame/capturepack/issues/149)).
- 저장 뒤 작업(After Save Actions)의 결과를 보여 주고 실패한 작업을 손으로 다시 돌릴 수 있습니다. 실패한 작업이 저절로 다시 돌지 않습니다 ([#165](https://github.com/r2cuerdame/capturepack/issues/165), [#169](https://github.com/r2cuerdame/capturepack/issues/169)).
- 설정 파일을 잠깐 못 읽거나 파일이 손상돼도 기존 설정이 초기값으로 덮이지 않습니다 ([#574](https://github.com/r2cuerdame/capturepack/issues/574)).
- 편집 중인 캡처는 자동 정리나 설정의 삭제 버튼으로 휴지통에 가지 않고, 다시 그리기가 실패해도 기존 영상·정지 화면이 지워지지 않습니다 ([#583](https://github.com/r2cuerdame/capturepack/issues/583), [#544](https://github.com/r2cuerdame/capturepack/issues/544)).
- 기록 창과 저장 공간 표시가 압축 파일을 매번 다시 읽지 않아 덜 멈칫하고, '1024 KB' 같은 크기 표기와 같은 이름 압축 파일을 짝으로 잘못 묶던 문제를 고쳤습니다 ([#515](https://github.com/r2cuerdame/capturepack/issues/515), [#517](https://github.com/r2cuerdame/capturepack/issues/517), [#521](https://github.com/r2cuerdame/capturepack/issues/521)).
- 크롬 연결이 지워진 파일을 가리키면 앱이 시작할 때 스스로 고치고, 설정의 연결 해제는 이 설치본의 연결만 지웁니다 ([#587](https://github.com/r2cuerdame/capturepack/issues/587), [#591](https://github.com/r2cuerdame/capturepack/issues/591)).
- 선택 항목이 빠진 팩도 읽기·다시 편집·내보내기·MCP에서 오류 없이 열리고, MCP가 모든 모니터의 프레임과 영상을 보여 줍니다.

The full list is in [CHANGELOG.md](../../CHANGELOG.md) under 0.6.0 and 0.6.1.

## Integrity

The Windows build is unsigned, so SmartScreen may warn. Check the installer
against `SHA256SUMS.txt` attached to the published release.

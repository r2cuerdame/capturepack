# CapturePack 0.6.5

CapturePack 0.6.5 keeps the DOM of a long web page when the Chrome toolbar
captures the whole page.

## 바뀐 점

- 크롬 툴바 원클릭 전체 페이지 캡처가 긴 페이지에서도 페이지 전체의 DOM을 담습니다. 이전에는 처음 4000개 요소에서 멈춰서 그림 아래쪽에는 DOM 문맥이 없었습니다. 확장 0.4.5는 전체 페이지를 20000개 요소까지 걷습니다.
- DOM을 실은 헤더가 너무 커서 브라우저 연결이 끊기고 캡처가 사라지던 경우를 막습니다. 3 MiB를 넘으면 앞부분만 보내고 잘렸다고 표시합니다.

The full list is in [CHANGELOG.md](../../CHANGELOG.md) under 0.6.5.

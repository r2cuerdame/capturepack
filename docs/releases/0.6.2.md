# CapturePack 0.6.2

CapturePack 0.6.2 fixes mouse and screen stutter while recording on a 4K
high-refresh display.

## 바뀐 점

- 고해상도·고주사율 화면에서 리플레이 녹화가 GDI 대체 경로로 넘어가면 마우스와 화면이 끊기던 문제를 고쳤습니다. 대체 경로가 세션 끝까지 남지 않고, 1분 뒤부터 15분까지 간격을 두 배로 늘리며 원래 녹화 경로를 다시 시도합니다.
- 리플레이 도우미는 보통보다 낮은 우선순위로 돌고, CapturePack 프로세스는 보통보다 높은 우선순위로 돌지 않습니다.
- GDI 대체 경로가 축소에 HALFTONE을 쓰지 않고, 프레임 사이에 CPU를 돌리며 기다리지 않습니다.

The full list is in [CHANGELOG.md](../../CHANGELOG.md) under 0.6.2.

# CapturePack 0.6.4

CapturePack 0.6.4 fixes a loop that used about one CPU core after the program
that started CapturePack closed.

## 바뀐 점

- CapturePack을 띄운 터미널이나 셸이 닫히면, 콘솔에 쓸 때마다 오류가 나고 그 오류를 다시 콘솔에 쓰는 반복이 생겨 CPU 코어 하나를 계속 썼습니다. 이제 닫힌 콘솔에는 더 쓰지 않고, 그 사실을 `main.log`에 한 번 남긴 뒤 로그는 파일에만 씁니다.

The full list is in [CHANGELOG.md](../../CHANGELOG.md) under 0.6.4.

Plugins

🟢 Windows UI Automation

While enabled, a local background helper watches visible window and control changes and keeps the bounded history used by Object Pick. It reads UI state only — never your keyboard or mouse input — and nothing leaves this machine. Turning it off stops the helper and clears the collected control history.

Tracks visible Windows controls in the background so past frames can select real objects. Turning it off stops the helper and clears its cache.

⚪ Chrome DOM capture

Load the extension folder in your browser once with developer mode on, paste the ID it is given, and Connect registers the native messaging host for every Chromium browser on this machine. Nothing leaves the machine, and the page is read only when you pick an element.

Stores what you clicked — selector, role, text, URL — instead of the pixels it was drawn with.

    1. 1
      Open your browser's extensions page The folder's path goes on the clipboard at the same time.
      chrome://extensions
      No Chromium browser could be started — paste the address above into your browser instead.
    2. 2
      Turn on Developer mode, then "Load unpacked" Paste with Ctrl+V in the folder box and confirm.
    3. 3
      Connected CapturePack registers itself with the browser and waits for the extension to say hello.
    4. 4
      Allow the browser Open any ordinary web page, click the CapturePack icon in the toolbar, and choose Allow. Chrome asks once. After that a capture brings the page with it and you press nothing in Chrome — the icon goes back to picking a single element. Your capture hotkey is a Windows shortcut, so Chrome never sees it. A page reaches an extension only for a click made inside Chrome, or for a browser you have allowed. Nothing is held until you allow it, and chrome://extensions takes it back at any time.

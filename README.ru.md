## Процесс

1. **Вернитесь назад** — при включённой по умолчанию фоновой записи нажмите
   `Ctrl+Alt+C` после ошибки. Длительность настраивается от 1 до 60 секунд.
   Если выключить запись, ничего не записывается.
2. **Выберите объект** — Object Pick сохраняет наблюдавшиеся границы, доступное имя, тип
   элемента и момент выбора. Если дочерний элемент недоступен, используется настоящее окно.
3. **Отследите движение** — окно и элемент наблюдаются по часам повтора. Каждый образец
   указывает дисплей, поэтому повторно открытый многомониторный пакет сохраняет время и
   координаты даже при переходе объекта между мониторами.
4. **Передайте контекст** — отправьте папку или позвольте ИИ читать уже сохранённые пакеты
   через необязательный локальный MCP-сервер только для чтения.

### Источники контекста

- **Windows UI Automation (встроено):** доступное имя, семантический тип, AutomationId,
  идентичность процесса/окна и наблюдавшиеся границы, если приложение их предоставляет.
- **Chrome DOM (необязательное расширение-превью):** селектор, роль, текст и URL явно
  выбранного элемента; расширение не транслирует DOM постоянно.
- **Окно HWND как запасной вариант:** сохраняет настоящее окно и его наблюдавшуюся
  геометрию вместо выдуманного объекта.

### Нужен только снимок?

`Ctrl+Alt+S` открывает выбор области; её можно без разрыва протянуть через границы мониторов.
**Полноэкранный снимок** явно сохраняет все дисплеи в одном изображении виртуального рабочего
стола. Снимок открывается в том же редакторе в масштабе 100%, когда это возможно. В пакете
изображения нет видео и `timeline.json`; область хранит только выбранные пиксели и положение,
без скрытого полного экрана или другого монитора.

## Содержимое пакета

```text
Видеопакет                       Пакет изображения
replay.mp4 или replay.webm       snapshot.png
replay_annotated.webm (необяз.; только если объявлен в manifest)
snapshot.png                     report.md · README.md · skills/
annotations.json · timeline.json plugins/ (необязательно)
plugins/ · manifest.json         manifest.json (capture_kind: image)
                                  без повтора и временной шкалы
```

Объекты и траектории — необязательные доказательства. Если их не удалось наблюдать, пакет
сообщает об этом и не выдумывает контекст.

## MCP

Необязательный [MCP](https://modelcontextprotocol.io)-сервер только для чтения включён и
автоматически запускается по умолчанию на `http://127.0.0.1:39393/mcp`. Его можно остановить
или убрать из автозапуска в Настройки → MCP. Он читает только уже сохранённые пакеты и не
может начать захват. Используйте `capturepack_history`, `capturepack_open` или
`capturepack_latest`. Подробнее: [docs/MCP.md](docs/MCP.md).

## Настройки и диагностика

- В Настройки → Захват отдельно меняются сочетания для видео
  (`Ctrl+Alt+C`) и изображения (`Ctrl+Alt+S`), длина повтора и частота 1–30 fps.
- Информация → **Открыть папку журналов** открывает локальную диагностику.
  Журналы никогда не загружаются автоматически.

## Конфиденциальность перед отправкой

Пиксели, заголовки окон, доступные имена и поля DOM могут содержать конфиденциальные данные.
CapturePack не загружает снимки, телеметрию или отчёты о сбоях. Единственный внешний запрос
приложения — необязательная проверка обновлений GitHub, которую можно отключить.

Размытие не изменяет оригинал: оно защищает аннотированные представления, но `snapshot.png`
и исходный повтор в полном пакете остаются без скрытия. Проверьте оригинал и не отправляйте
полный пакет, если в нём есть закрытая информация.
